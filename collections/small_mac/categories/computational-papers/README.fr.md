Les titres sont conservés dans la langue de chaque manuscrit figé.

Les numéros d’affichage 11–58, les identifiants de lot et les identifiants internes d’origine sont conservés. Les identifiants publics `phys-smallmac` renvoient aux répertoires canoniques des projets. La correspondance figure dans [`id-map.json`](../../id-map.json).

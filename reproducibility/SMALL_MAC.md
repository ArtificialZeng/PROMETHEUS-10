## Collection commands

```bash
python3 reproducibility/verify_package.py
python3 reproducibility/verify_small_mac.py --all
python3 reproducibility/build_small_mac_papers.py --all
```

The first command verifies the full-tree SHA-256 manifest, and the second verifies every SmallMac project record. The manuscript builder needs `latexmk` and creates disposable build directories under the ignored `reproduction-runs/` path. None of these commands submits, uploads or modifies a frozen PDF.

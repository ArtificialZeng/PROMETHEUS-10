## Frozen scientific claim

For every real coupling vector (a,b,c,d,e,f), the eight-level spectrum of H=a Z_2+b Y_1 X_2+c X_1 Y_2+d Z_1 Y_3+e Y_1 X_3+f Z_3 is, with multiplicity, the signed-sum spectrum of three nonnegative one-particle energies if and only if c d (a^2-f^2)(b^2-e^2)=0; equivalently the locus is exactly c=0, d=0, a=plus-or-minus f, or b=plus-or-minus e. This claim is spectral and does not claim a uniform structural CAR-mode construction.

## Original topic (Chinese source text)

五站点环的转移概率具有平移对称性，是否总能选择同样对称的酉实现？

## Frozen scientific claim

Let d>=2 and let B be a d-by-d circulant bistochastic matrix with B\[i,j\]=b\[(i-j) mod d\]. If B\[i,j\]=|U\[i,j\]|^2 for some arbitrary U in U(d), then for every Fourier mode k, lambda_k(B)=tr(D_k U D_k^dagger U^dagger)/d belongs to the closed unit d-hypocycloid H_d. For d=5, the circulant matrix generated by b=(209/500,3/40,7/500,3/40,209/500) satisfies every row and column bracelet inequality but is not unistochastic, because lambda_1=((465+343*sqrt(5))/2000) exp(i*pi/5) lies strictly outside H_5. Consequently, a five-hypocycloid violation cannot supply the general-unitary-versus-circulant-unitary separator required to disprove P_5.

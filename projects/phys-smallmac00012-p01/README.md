## Frozen scientific claim

For every U,V in U(3), there exists W in U(3) such that |W_ij|^2 equals \[B(V)B(U)\]_ij for all i,j. Equivalently, the order-three unistochastic set U_3 is a monoid under ordinary matrix multiplication.

## Frozen scientific claim

For every qubit CPTP map with positive-definite Choi matrix, using the same four-outcome orthogonal projective measurement on each fresh minimal environment, the separately optimized current-outcome Markovian polar-recovery and full-history/final-only Bayesian entanglement fidelities are equal at three uses. More strongly, within the same physical model they are equal for every positive integer n and have common value (1+||Q||_*^n)/2, where Q is the determinant polarization matrix of any minimal Kraus frame.

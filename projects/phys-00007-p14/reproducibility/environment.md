# Environment

Python diagnostics: Python 3, standard-library math and pathlib; no third-party Python dependencies. Floating-point calculations are ordinary doubles, without directed-rounding guarantees.

Build: pdfLaTeX, BibTeX; standard article class, T1 font encoding, lmodern, amsmath, amssymb, amsthm, geometry, microtype and hyperref; plain bibliography style. Exact observed versions are recorded in build/environment.log.

No system installation is needed. The scientific error bound is analytic and does not rely on a specific interpreter or TeX version.

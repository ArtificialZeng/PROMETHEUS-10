## Original topic (Chinese source text)

对称三态环是否恢复原相位滞后上界？

## Frozen scientific claim

In the complete symmetric K3 model k_ij(t)=k0 exp\[(E_i(t)-E_j(t))/2\], for arbitrary finite static offsets and every non-gauge finite real Fourier perturbation E(t)=E0+epsilon e(t), the unique periodic state has A=epsilon^2 A_2+O(epsilon^3) and B=epsilon^2 B_2+O(epsilon^3), with B_2>0 and A_2>2 k0 B_2. Thus the limiting weak-drive phase is strictly below arctan\[Omega/(2 k0)\] at finite offsets; the uniform factor 2 is sharp in the effective-two-state infinite-offset limit. This does not settle the original all-amplitude claim.

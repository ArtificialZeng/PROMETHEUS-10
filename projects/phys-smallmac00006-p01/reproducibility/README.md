# Reproducing the finite Glauber annealing counterexample

This package contains the exact eleven-state example reported in
`manuscript/main.tex`. The manuscript includes a self-contained scalar
certificate and the proof for every independent energy perturbation
`|delta(E_i/epsilon)| <= 1/1000`. No simulation, random seed, experimental
data, or floating-point sign test is needed.

Use the package root as the working directory. Python 3.9.6, SymPy 1.14.0,
Matplotlib 3.9.4, and TeX Live 2026 were present in the tested environment.
The scalar and full-matrix calculations use the Python standard library;
the independent edge representation and baseline comparison use SymPy.
Matplotlib is needed only to regenerate the figure. No software is installed
by the scripts. The requirements file records existing versions.

## Exact checks

Run each command to completion in the foreground:

```sh
python3 -B reproducibility/scalar_certificate.py
python3 -B reproducibility/replay.py
```

The scalar certificate exits silently with code zero on success; a failed
assertion is a failed check. The second command makes a uniquely named
`build/replay-*` directory, copies the preserved source implementations there,
and runs them sequentially. It never rewrites the accepted files under
`evidence/`. It repeats the four-spin equilibrium baseline, propagates the
full eleven-state matrices, independently accumulates synchronous edge flux,
and enumerates all 704 two-update proposal/acceptance histories. It verifies
equality with the bundled full rational matrix certificate. Read the actual
`replay-summary.json` and per-command logs under that newly printed directory.

Expected exact signs are `A1 > 63/125` and `mean > 251/500`.
The baseline is `Z=41/2`, `R=16/41` for the periodic four-spin ferromagnetic
Ising chain at `beta*J=log(2)/2`. This baseline is a substitution into the
published finite-chain formula, not a new result. Complete rational data
are in `evidence/layered-exact-a.json` and `evidence/layered-exact-b.json`.
The latter data were generated by a separate arithmetic representation;
three programs agreeing is corroboration, not external peer review.

## Display and manuscript

```sh
python3 -B reproducibility/make_display.py
python3 -B reproducibility/build_manuscript.py
```

Display regeneration compares its scalar results with the preserved full
matrix certificate before writing `manuscript/table-rows.tex`,
`reproducibility/display-data.json`, and
`manuscript/figures/occupations.pdf`. Only bar heights are converted to
floating point. The figure draws the exact 22-edge graph beside probabilities per microstate, not class totals.
Run this regeneration on an unfrozen draft or a copy: changing a manuscript
dependency requires renewed release review.

The build script creates a fresh `build/clean-*` tree with explicit local
dependencies and executes pdfLaTeX, BibTeX, and two more pdfLaTeX passes,
with shell escape disabled. Its printed build record gives the actual PDF,
compiler logs, bibliography log, source hashes, and dependency recorder.
No network operation or submission occurs. Required TeX packages include
REVTeX 4.2, AMS math, graphicx, booktabs, fancyvrb, and hyperref.

## Source and domain

The defining kernel, activity, equilibrium identity, and conjecture are in
[Luo et al., arXiv:2311.10424v1](https://arxiv.org/html/2311.10424v1),
PDF pp. 5-6, Eqs. (30)-(33) and (38)-(41). The averaged-activity use is in
[arXiv:2311.10422v1](https://arxiv.org/abs/2311.10422v1), p. 4.
The finite-chain baseline is in
[Burovski et al., arXiv:1907.06776v2](https://arxiv.org/abs/1907.06776v2),
Appendix, subsection B, Eq. (24). Third-party PDFs are not part of this package.

The graph is a complete finite classical state space with uniform-neighbor
proposals. All temperatures and energies are finite. This example does not
establish a result for SK-only, hypercube-only, or slowly cooled subclasses,
and does not test the complete final annealing-performance formulas.

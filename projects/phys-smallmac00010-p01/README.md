## Original topic (Chinese source text)

四能级酉跃迁掺入均匀噪声后，能否总由另一个单次酉跃迁实现？

## Frozen scientific claim

For any order n with a real normalized Hadamard F and any real orthogonal projector P, U=F(I-2P) has the exact flat-noise transition ray |V_lambda,ij|^2=(1-lambda)|U_ij|^2+lambda/n for every lambda in \[0,1\], with V_lambda=sqrt(1-lambda)U+i sqrt(lambda)F unitary. Within this fixed real quadrature ansatz the condition is also necessary: F^T U is a symmetric orthogonal involution. At n=4 the rank-two projector component contains a locally four-dimensional image of noncirculant B(U) matrices.

# Reproducing the local manuscript

The analytic result is the all-d positive-spectrum criterion and the complete qutrit criterion in the manuscript. The full signed problem for d>=4 remains unresolved. Computational checks establish finite-dimensional transcription and algebra agreement; the all-d conclusion follows from the manuscript's real-trace and full-O(d) averaging proof, not a finite scan.

Work in a disposable extracted copy: the source scripts regenerate JSON and logs next to their own files. Never run them in an accepted scientific dossier without preserving its original outputs and arranging any required fresh audit.

## Environment

The actual writing environment was Python 3.12.14, SymPy 1.14.0, NumPy 2.5.3, SciPy 1.18.1 and Matplotlib 3.11.2. Versions are listed in requirements.txt; libraries themselves are not redistributed. A functioning TeX installation with latexmk, pdfLaTeX, BibTeX and the standard article, amsmath, amssymb, amsthm, geometry, graphicx, microtype, natbib, lmodern and hyperref packages builds the paper. No custom class or style is required.

From the extracted package root, with python referring to an environment containing the stated packages:

    python evidence/reproduce/input_a.py
    python evidence/reproduce/input_b.py
    python evidence/reproduce/check_reproduction.py
    python evidence/research/pass3/verify_positive_region.py
    python manuscript/figures/make_qutrit_region.py
    latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build manuscript/main.tex

The first construction transcribes the transpose/trace map on matrix units; the second independently reconstructs normalized Choi-eigenvector/Kraus input. The checker compares them entry by entry for symbolic x,y at d=3,4,5,6 and reproduces the published qutrit output spectrum. Input A and B do not read each other's computed answers. The scripts were generated by the same research workflow; the fresh referee's separate reconstruction is retained in the private audit dossier and is not claimed as external peer review.

The pass-3 script independently rebuilds the benchmark's sector logarithm, projected Choi matrix, jump dissipator and projector exponential using SymPy. Its dense logarithm and 200 sampled nonprincipal-branch calculations are optional diagnostics. They do not establish the all-branch theorem. Outputs are evidence/reproduce/input-a.json, input-b.json, input-comparison.log, baseline.log, and evidence/research/pass3/positive-region-audit.json and .log.

The figure script uses exact Fraction arithmetic for rational boundary coordinates. With rational t, it sets s=t^3 and a=t or t^5, then x=(2-5s+3a)/6 and y=(2+s-3a)/3. The CSV stores those exact fractions, and the PDF samples the analytic boundaries only for rendering. Neither endpoint t=0 nor t=1 belongs to the frozen domain. The figure assertions and the two example points are reported in figure-data.json. No sampled area, numerical threshold or experimental precision is claimed.

The resulting manuscript is build/main.pdf. In the local working dossier the reviewed draft instead uses build/release-final-1c77995c289b/main.pdf. Final citation, clean-build and every-page visual acceptance are tasks for a fresh release review. Human authorship and scientific approval remain pending.

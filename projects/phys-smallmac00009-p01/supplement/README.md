# Complete four-state response certificate

This package supports the common rooted-tree edge-marginal decomposition
in the accompanying manuscript. The theorem applies to twelve strictly
positive finite rates on the complete four-state graph and first-order
static response with arbitrary signed logarithmic rate slopes. It does
not establish a general-graph theorem, full-hull attainability, or a
coupling of full rooted-tree probability laws.

## Run the exact checkers

From the top level of this source package:

```sh
mkdir -p check-output
cd check-output
python3 ../supplement/check_cofactors.py > cofactor-stdout.log
python3 ../supplement/check_prufer.py > prufer-stdout.log
```

Both programs read `certificate.json` relative to their own script path;
they write only in the chosen output directory. Do not use Python's `-O`
option, which disables assertions. A nonzero exit is a failed run. The
result files report `status: pass` only after the actual checks complete.
The outputs are `cofactor-results.json`, `cofactor-checks.log`, and
`prufer-results.json`, together with the redirected standard output.

Python 3.9.6 was used for the recorded runs. Only standard-library modules
are needed; no requirements install, NumPy, SciPy, SymPy, GPU, or internet
connection is required to verify the certificate. Runs are sequential and
single process. Memory use was not measured and no timing-performance
claim is made. The current package was replayed after its path-only
adaptation for distribution. That replay is not a new independent review.

The cofactor checker generates trees by parent maps, regenerates all
65,536 families and singleton classes, and derives polynomials from
3-by-3 Laplacian cofactors before substituting balanced-flow variables.
Its recorded run passes 5,141 checks. The separately implemented Prüfer
checker expands tree products by cycle-label multisets. It checks all
93 monomials and 4,464 central component identities, all 346 singleton
families, and 210 exact positive-rate response cases against row-generator
linear solves. Both checkers read the proposed rational supports as
untrusted witnesses; neither substitutes saved numerical answers for
regeneration. Read the analytic proof as well: successful finite code
execution alone does not establish the stationary-flow reduction, its
physical interpretation, or novelty.

## Certificate format

`certificate.json` is the original exact witness data. It contains:

- `variables`: `(s01,s02,s03,s12,s13,s23,A,B,C)`.
- `edge_order_destination_source`: the ordered edges `(01,02,03,10,12,13,20,21,23,30,31,32)`; `ij` denotes the arrow `j -> i`.
- `edge_rate_variable_indices`: the nine-variable linear substitution specified in the manuscript.
- `records`: 93 records, each with a degree-three exponent vector, common denominator coefficient, full 4-by-12 marked-edge numerator, unique-family IDs, and exact rational weights as strings.

Tree triples use zero-based indices into that edge order, sorted internally
and then lexicographically at each root. Each root has tree indices 0--15.
The family ID is `4096*t0 + 256*t1 + 16*t2 + t3`. Its uniqueness is defined
by the entire directed multiplicity vector across all four roots.

The `lp_status`, timing and diagnostic fields describe historical support
discovery; they are not proof. Exact coefficients and all singleton
statuses are regenerated by the checkers. The floating solver selected
candidate supports during discovery only. There are 82 denominator
coefficients equal to 1, ten equal to 2, and one equal to 3 (ABC).
Weights are 1, 1/2, or 1/3. The complete identities, together with the
analytic nonnegative cone cover, establish the continuum claim; finite
rate examples serve as convention checks.

## Regenerate tables and compile

From the package top level, run:

```sh
python3 supplement/make_tables.py
python3 manuscript/build.py
```

The first command regenerates all tree-decoding and coefficient rows from
the certificate. It is presentation code, not an additional independent
checker. The second makes a new empty build directory under `build/`,
copies the listed TeX/Bib/figure inputs into it and runs latexmk/pdflatex
and BibTeX there. It prints the generated PDF and compiler-log locations.
The required TeX packages are listed in `manuscript/main.tex`; they are
standard TeX-distribution packages and are not redistributed here.

The canonical residual-flow diagram is authored TikZ source in
`manuscript/figures/cone.tex`; it displays the exact analytic rate map,
not sampled or experimental data. The source package includes no copied
third-party papers, images, or author-code archive. Journal declarations,
authorship confirmation, and human scientific review remain pending in
`AUTHOR_HANDOFF.md`.
